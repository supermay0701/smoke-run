# 🚬 菸槍快跑！

一款反諷風格的直式跑酷小遊戲。你是一個老菸槍：撿菸、躲衛生局和警察，然後看看自己的肺能撐多久。

**▶ 線上試玩：https://supermay0701.github.io/smoke-run/**

## 玩法
- 滑鼠／手指左右拖曳，或用 ← → 鍵移動
- **尼古丁**會一直掉，太低就戒斷手抖；尼古丁越高，移動越靈活
- **肺損傷**不抽菸時會慢慢恢復，但會留下永久疤痕；滿了就 Game Over
- 菸品下方的 ● 越多越傷肺
- 🏥 醫院可以治療肺部，但要花錢
- 😇 碰到董氏基金會會暫時「懂事」
- 三種難度：小菸槍、老菸槍、菸蟲

## 技術
單一 `index.html`，純 HTML5 Canvas + JavaScript，不需要任何安裝或建置。
